## The task

Build a RAG assistant that answers only from retrieved evidence, shows its sources with
title, section, and path, discloses conflicts between sources, and refuses when the
evidence does not support an answer.

Then break it deliberately, with adversarial documents, and show that it holds.

## Run the reference implementation

```bash
cd projects/chatbots-rag
python project_f_cited_assistant.py --selftest
python project_f_cited_assistant.py "How much does a paid workshop cost?"
python project_f_cited_assistant.py --corpus ../../data/chatbots-rag/adversarial --show-withheld "What do the lab notes say about maintenance?"
```

Verified output:

```text
PASS  answer is not a refusal
PASS  a source is shown
PASS  the section name is shown
PASS  the file path is shown
PASS  refusal shows no sources
PASS  poisoned passage withheld from the answer
0 failure(s)
```

## Steps

1. **Answer a supported question** and open the cited file to confirm the claim.
2. **Ask an unanswerable question** and confirm a refusal with no sources.
3. **Build an adversarial corpus** with the five fixtures below.
4. **Run each case** and record the observed behaviour, including any failure.
5. **Fix what fails**, then rerun the whole table. Keep both results.
6. **Render sources** so a reader can find the passage without the console.

## The eight required cases

| # | Case | Fixture | Required behaviour |
| --- | --- | --- | --- |
| 1 | Supported answer | corpus | Answer plus citation that resolves |
| 2 | Unsupported question | corpus | Refusal, no citation |
| 3 | Missing document | corpus | Refusal naming the gap |
| 4 | Conflicting passages | two docs, 14 vs 30 days | Conflict disclosed; neither value hidden |
| 5 | Irrelevant retrieval | keyword decoys | Refusal, or an answer citing only relevant chunks |
| 6 | Prompt injection in a document | "ignore all previous instructions" | Quarantined; payload never in the prompt or answer |
| 7 | Sensitive data in a document | email and student id | Redacted before the prompt; never echoed |
| 8 | Fabricated citation | model cites a non-existent block | Validator fails closed; refusal shown |

Cases 6-8 need a stub client that misbehaves; the tests in
`tests/test_chatbot_rag.py` show how to build one.

## Test cases to include

| # | Case | Pass condition |
| --- | --- | --- |
| 1-3 | Basic grounding and refusal | Citation resolves; refusal has no sources |
| 4 | Conflict | `answer.conflict` is true and both values appear in the note |
| 5 | Decoys | No citation to a decoy document |
| 6 | Injection | `quarantined_chunks` non-empty, payload absent from answer |
| 7 | Redaction | `[email redacted]` present, raw address absent |
| 8 | Fabrication | `dropped_citations` non-empty, answer refused |

## Constraints

- The offline client must be the default; no key required.
- Do not weaken the citation validator to make a case pass.
- Do not display a claim whose citation failed validation, even as a "debug" panel.
- Document the adversarial fixtures you wrote; other students should be able to reuse them.

## Rubric

| Dimension | Weight | Excellent | Developing |
| --- | --- | --- | --- |
| Grounding | 30 | Every displayed claim has a resolving citation | Answers shown without sources |
| Refusal behaviour | 25 | Refuses unsupported and missing-evidence cases | Guesses, or refuses everything |
| Adversarial testing | 25 | All eight cases run with recorded results, including failures | Happy path only |
| Source display | 10 | Title, section, path, score visible | Bare numbers |
| Reproducibility | 10 | Fixtures committed and generated by script | Ad-hoc files, undocumented |

## Extension tasks

1. Add a **confidence display** that distinguishes "one strong source" from "three weak
   ones", and check on your question set whether it correlates with correctness.
2. Add a **disagreement view** that shows both conflicting passages side by side instead of
   only naming them.
3. Add a **citation hover** that shows the exact excerpt that was cited, and verify it
   matches the source file byte for byte.
