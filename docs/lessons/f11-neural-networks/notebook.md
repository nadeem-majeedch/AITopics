## Troubleshooting

| Symptom | Diagnosis | Fix |
| --- | --- | --- |
| `ModuleNotFoundError: sklearn` | The kernel uses a different interpreter | Print `sys.executable`; select the `.venv` kernel |
| `ConvergenceWarning` from `MLPClassifier` | Iteration limit reached before convergence | Keep the scaler, raise `max_iter`, or ignore once accuracy is stable |
| MLP accuracy is not above logistic (assertion fails) | Unscaled inputs or modified architecture | Restore `StandardScaler` and `hidden_layer_sizes=(16, 8)` |
| `AttributeError: 'MLPClassifier' object has no attribute 'coefs_'` | The model was not fitted | Run the section 4 cell before section 5 |
| Figure missing despite no error | Notebook launched from the repository root | Look in `E:\AITopics\outputs\`, or relaunch from `notebooks/foundations/` |
| `ValueError: Expected 2D array` in the boundary cell | Grid reshaped incorrectly after an edit | Use `np.c_[xx.ravel(), yy.ravel()]` as in the notebook |
| Plot window never appears | The notebook forces the non-interactive `Agg` backend | Open the saved PNG instead of expecting a window |
| Accuracy differs by more than 0.03 from 0.94 | Cells run out of order, or the seed was removed | Restart the kernel and run all cells |

If a failure is not in this table, record the exact message, your
`sys.executable`, your package versions, and the cell that failed. That record is
evidence for the assessment.
