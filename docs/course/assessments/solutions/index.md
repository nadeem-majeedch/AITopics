Answer keys for every bank. Each file opens with the marking standard used, then
gives the answer and the reasoning a strong response contains.

!!! warning "Read the question first"
    These files exist so you can check your work, not so you can skip it. Reading a
    solution produces recognition, not recall. Attempt the question in writing first;
    the effort is what makes the answer stick.

## A note on numbers

Every numeric answer in these files was computed, not estimated: the metric
definitions were implemented for the course and the values were checked by running the
calculation. Where a question admits several defensible answers (the scenarios, most
of the conceptual questions), the file says so and describes what would make an
alternative answer strong.

None of this constitutes grading. No submission is reviewed, and no result here is
verified by the course author.

## How to use a miss

1. Read the reasoning, not just the answer.
2. Find the module that covers it and reread that section.
3. Redo the question two days later without notes.
4. If you miss it again, write the explanation in your own words in `progress.md`.

A bank you scored 70% on twice, with the misses understood, is worth more than a bank
you scored 95% on once by reading the key.
