# Licensing and attribution register

Audit date: **2026-11-07**. Scope: all repository content, generated course data,
direct Python dependencies, pretrained-model references, and bundled media.

**Approved and implemented:** the instructor approved MIT for original source
code, CC BY 4.0 for original educational content, CC0 1.0 for verified original
synthetic datasets, and upstream terms for third-party material. The texts,
scope manifest, notices, validator, and tests are in the working tree. This is a
provenance register, not legal advice.

Status meanings:

- **Verified** - the repository or authoritative upstream documentation contains
  evidence for the statement.
- **Pending verification** - the item is documented but the evidence is
  incomplete, version-dependent, or not installed in the audited environment.
- **Unresolved** - no authoritative terms were found; do not claim a licence.
- **Excluded third-party material** - not distributed under the repository
  licence; upstream terms apply.
- **Not applicable** - the item is not distributed by this repository.

The decision record is the
[Licensing decision package](licensing-decision-package.md). The structured
third-party list is the [Third-party inventory](third-party-inventory.md). The
student-facing map is `LICENSES/README.md`.

## SSDLite weight investigation

| Field | Finding |
| --- | --- |
| Architecture | `torchvision.models.detection.ssdlite320_mobilenet_v3_large` |
| Weight enum | `SSDLite320_MobileNet_V3_Large_Weights.COCO_V1` (also `DEFAULT`) |
| Exact artifact | `ssdlite320_mobilenet_v3_large_coco-a79551df.pth` |
| Official source | <https://download.pytorch.org/models/ssdlite320_mobilenet_v3_large_coco-a79551df.pth> |
| Model documentation | <https://docs.pytorch.org/vision/stable/models/generated/torchvision.models.detection.ssdlite320_mobilenet_v3_large.html> |
| Source | <https://github.com/pytorch/vision/blob/main/torchvision/models/detection/ssdlite.py> |
| Parameters / size | 3,440,060 parameters; about 13.4 MB |
| Training data | COCO 2017; 80 foreground classes; COCO-val2017 box mAP 21.3 |
| Code licence | BSD-3-Clause, per the torchvision repository `LICENSE` |
| Weight licence | **Unresolved.** No separate weight licence is stated. Torchvision's documentation says pretrained models "may have their own licenses or terms and conditions derived from the dataset used for training" and places the responsibility for permission on the user. PyPI repeats this notice; only the SWAG models are called out there as CC BY-NC 4.0. |
| COCO terms | Annotations and website are CC BY 4.0; the COCO Consortium does not own the images, which remain subject to Flickr terms. |
| Conclusion | Calling the weights MIT, BSD-3-Clause, or Apache-2.0 is **not supported**. The correct status is **unresolved**. |
| Redistribution | The repository does not bundle the weights. `SSDLiteDetector` downloads them to `.cache/torch` at runtime. Do not redistribute the weight file or a fine-tuned checkpoint without a separate review. |
| Attribution | If used, cite torchvision and COCO and retain the torchvision BSD-3 notice. Attribution does not by itself resolve the weight terms. |

Authoritative references:

- Torchvision model-weight notice:
  <https://docs.pytorch.org/vision/stable/models.html>
- Torchvision BSD-3 licence:
  <https://github.com/pytorch/vision/blob/main/LICENSE>
- COCO terms of use:
  <https://cocodataset.org/#termsofuse>
- PyPI weight notice:
  <https://pypi.org/project/torchvision/>

The repository's previous statements that the weights were BSD-3, and one
statement that they were Apache-2.0, were both unsupported. The code, lab output,
and video model card now say the code is BSD-3-Clause and the weight terms are
unresolved. No historical measurement or experiment result was changed.

## Validation

`python scripts/check_licensing.py` checks the required files, exact official
texts, scope manifest, documentation statements, third-party exclusions, SSDLite
status, scope coverage, P06 CC0 record, and SPDX consistency. The eleven licensing
tests cover missing files, missing exceptions, conflicting identifiers,
unresolved weights, missing synthetic attribution, the correct mixed
configuration, a tampered legal text, unclassified files, non-content
placeholders, overlapping scopes, and the complete repository configuration.

Local validation on 2026-11-07 passed, including the full Python suite, notebook
JSON validation, strict MkDocs build, built-site prefix check, and `pip check`.
GitHub Actions has **not** executed because no commit or push was performed.
