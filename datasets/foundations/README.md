# Foundation synthetic datasets

The foundation labs use four synthetic tables generated by
[`scripts/make_foundation_data.py`](../../scripts/make_foundation_data.py).
They contain no real people, no scraped text, and no personal data.

| Dataset | Rows | Target | Used in |
| --- | --- | --- | --- |
| `house_prices.csv` | 600 | `sale_price` | F05, F06, F08 |
| `student_performance.csv` | 500 | `passed`, `final_score` | F03, F08, F09, F10 |
| `student_performance_messy.csv` | 510 (500 unique) | `passed` | F04 lab |
| `customer_segments.csv` | 420 | none (latent segment withheld) | F07 |

## Generate

```bash
python scripts/make_foundation_data.py
```

The command writes CSV files and a SHA-256 manifest to
`datasets/foundations/generated/`. Generated data is excluded from Git.

## Known limitations

The tables are deliberately simple. Relationships are mostly additive with
controlled noise, so they are suitable for learning workflows, not for claims
about real housing markets, students, or customers. The student table is not a
measurement of any real course, and it must never be used to make decisions
about people.
