# Video AI labs

The module starts at [Video AI](../../docs/lessons/video-ai/index.md). Its eight
lab briefs run from preprocessing to tracking, adaptation, action recognition,
and performance.

Runnable code and the synthetic video generator are in
[`projects/video-ai/`](../../projects/video-ai/). Generate the clips with
`python projects/video-ai/scripts/make_video_data.py` from the repository root.
No separate starter file is stored here.
