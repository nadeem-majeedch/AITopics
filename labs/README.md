# Labs

This directory holds optional starter files for labs. It is not the lab index.

- **Foundations:** [`labs/foundations/`](foundations/) contains the Markdown
  scaffolds used by F01-F13. The actual lab briefs are under
  [`docs/lessons/`](../docs/lessons/index.md).
- **Applied sections:** the lab briefs are in
  [`docs/lessons/`](../docs/lessons/index.md), and the runnable code is in
  [`projects/`](../projects/). The area directories here contain pointers only;
  they do not duplicate the briefs.

If you are looking for the course sequence, start with the
[course roadmap](../docs/course/roadmap.md). If you are looking for a notebook,
use the [Notebook Library](../docs/notebook-library.md).
